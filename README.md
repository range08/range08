## Featured Projects

### [Brick Breaker](https://github.com/range08/Brick-Breaker)

A portrait mobile 2D block-breaker built with **Unity 6.3 LTS and C#**.

The project includes multiball launching, trajectory prediction with CircleCast, object pooling, round progression, bonus blocks, Fever mode, automatic game-speed control, and play-test-driven difficulty balancing.

`Unity` `C#` `2D Physics` `New Input System` `Object Pooling`

### [Range Remote](https://github.com/range08/range-remote)

An open-source **remote MCP service for ChatGPT plugins**.

It connects computers and servers through an outbound-only agent and exposes controlled tools for filesystem access, Git inspection, file editing, and optional shell execution. The project includes OAuth 2.1 / OIDC, PKCE, JWT-based authorization, WebSocket device connections, and security-focused local policy enforcement.

`TypeScript` `Node.js` `MCP` `OAuth 2.1` `WebSocket` `Docker`
